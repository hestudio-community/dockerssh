# DockerSSH

Make your Docker container available as an SSH connection.

## Require

1. Linux Only.
2. bash.
3. git.
4. Latest docker.
5. Root Permission.
6. Latest Python LTS.
7. uv

## Install

1. First install [uv](https://docs.astral.sh/uv).
2. Run this command：

```bash
uv tool install hedockerssh
```

### How to use?

You can view the manual using this command：

```bash
dockerssh -h
```
